# Product Vision

# Vision Statement

LeadPilot exists to help engineering leaders become better coaches.

Instead of measuring productivity, LeadPilot builds a complete understanding of every engineer's professional journey by combining technical signals, human observations, and artificial intelligence.

Our mission is simple:

**Help every Team Lead have better conversations.**

---

# The Problem

Engineering leadership is built on context.

Unfortunately, context disappears.

A customer compliment is forgotten.

A production incident is forgotten.

A mentoring session is forgotten.

A difficult sprint is forgotten.

When performance reviews arrive months later, leaders depend mostly on memory.

Memory is biased.

LeadPilot exists to preserve context.

---

# What We Believe

Software development is a human activity.

Code is only one signal.

Great engineers contribute in many ways:

Helping teammates.

Improving communication.

Leading difficult conversations.

Supporting incidents.

Teaching.

Taking ownership.

None of these appear in GitHub metrics alone.

---

# Product Mission

Create a living history of engineering teams.

Every meaningful event should become part of the developer's story.

The platform should answer:

"What happened?"

instead of only

"How many PRs were merged?"

---

# Product Identity

LeadPilot is not:

* Engineering Analytics
* Employee Monitoring
* Productivity Tracking
* HR Software

LeadPilot is:

* AI Leadership Assistant
* Engineering Coaching Platform
* Team Memory
* Context Engine

---

# Product Vocabulary

To create consistency across the product, we use a specific vocabulary.

## Signals

Automatically collected data.

Examples:

GitHub PR

Review

Merge Time

Repository Activity

Future:

Jira

Slack

Azure DevOps

---

## Observations

Information added by humans.

Examples:

Customer praised communication.

Developer handled production incident.

Excellent ownership.

Mentored junior developer.

Needs support.

Communication issue.

Leadership moment.

---

## Timeline

The chronological history of a developer.

Signals and observations appear together.

This becomes the single source of truth.

---

## Insights

Generated by AI.

Examples:

"This engineer has gradually increased review participation."

"This engineer has recently become more involved in technical discussions."

---

## Talking Points

Suggestions for the next 1:1 meeting.

Examples:

Recognize customer praise.

Discuss review bottlenecks.

Ask about workload.

Celebrate recent ownership.

---

## Growth Areas

Potential coaching opportunities.

Examples:

Delegation

Communication

Architecture

Code Reviews

Planning

Leadership

---

## Achievements

Significant positive moments.

Examples:

Led production incident.

Received customer recognition.

Mentored teammate.

Completed critical migration.

Promoted team collaboration.

---

# Long-term Vision

Eventually LeadPilot should know enough context to help answer questions like:

"What should I discuss during tomorrow's 1:1?"

"Has this engineer been growing?"

"What achievements should I recognize?"

"Who may need support?"

"What changed since last month?"

Without the Team Lead needing to manually search through GitHub, Slack or Jira.

---

# Product Principles

Every feature must satisfy at least one of these goals.

Improve coaching.

Improve recognition.

Improve context.

Reduce manual work.

Increase trust.

Support better conversations.

If it doesn't help a Team Lead become a better leader, it should not be built.

---

# Trust Principles

Trust is the foundation of this product.

Developers should feel supported.

Never monitored.

Never ranked.

Never scored.

The product should encourage coaching, not surveillance.

---

# Success Metrics

A successful Team Lead should be able to:

Prepare for a 1:1 in under five minutes.

Remember important events from six months ago.

Recognize achievements more frequently.

Detect coaching opportunities earlier.

Spend less time gathering information.

Spend more time helping people grow.

---

# North Star

LeadPilot becomes the AI memory and coaching assistant for every engineering leader.

When someone asks,

"How has Sarah been doing over the last six months?"

the answer should already exist.
